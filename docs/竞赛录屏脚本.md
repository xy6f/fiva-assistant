# 智能财税AI助手 - 竞赛录屏脚本

## 项目技术亮点

- **双AI模型架构**：DeepSeek（智能对话） + 阿里云Qwen-VL（发票OCR识别）
- **技术栈**：Spring Boot 4 + Vue 3 + LangChain4j + Element Plus
- **SSE流式输出**：AI回复打字机效果，逐字显示
- **多租户隔离**：一账号一公司，数据安全

---

## 录屏脚本（约4分钟）

### 【开场 0:00-0:30】项目介绍

> 大家好，我带来的作品是《智能财税AI助手》。这是一个融合AI大模型能力的企业级财务管理系统，采用Spring Boot + Vue3 + LangChain4j技术栈，集成了双AI模型架构：DeepSeek负责智能对话，阿里云Qwen-VL视觉模型负责发票OCR识别。

---

### 【功能1：发票OCR智能识别 0:30-1:30】⭐重点

> 首先是AI发票识别功能。用户上传一张发票图片——

**操作步骤：**
1. 进入"发票上传"页面
2. 上传一张发票图片
3. 等待OCR识别（展示Qwen-VL模型提取过程）
4. 展示识别结果：发票号码、金额、税额、销售方、购买方自动填入

> 系统通过Qwen-VL多模态视觉模型，自动提取发票的关键信息，包括发票号码、金额、税额、销售方、购买方等，无需人工录入，准确率极高。

---

### 【功能2：AI财税智能对话 1:30-2:40】⭐重点

> 其次是AI财税助手，基于DeepSeek大模型，支持流式输出，实现打字机效果。

**操作步骤：**
1. 进入"AI对话"页面
2. 提问："帮我分析一下本月的收支情况"
3. 等待AI流式回复（展示逐字输出效果）
4. 继续提问："最近有什么税务风险需要注意？"
5. 展示AI专业回答

> AI助手可以回答财税专业问题，提供税务筹划建议，支持多轮对话，就像一个24小时在线的财税顾问。

---

### 【功能3：发票真伪查验 2:40-3:20】

> 系统还支持发票真伪查验功能，通过AI辅助分析发票要素的合理性，校验金额关系、税率合规性，防范虚假发票风险。

**操作步骤：**
1. 进入"发票管理"页面
2. 选择一张未查验的发票
3. 点击"查验"按钮
4. 展示查验结果（AI分析内容）

---

### 【功能4：其他AI能力 3:20-3:50】

> 系统还集成了AI税务筹划建议功能，根据企业财务数据，智能分析并给出节税方案。

**操作步骤：**
1. 展示仪表盘数据统计
2. 展示AI建议功能（如有）

---

### 【收尾 3:50-4:10】

> 系统还包含凭证管理、固定资产折旧（支持三种折旧方法）、工资管理、预算预警等完整财务功能，所有数据通过多租户隔离，保障企业数据安全。技术亮点是双模型架构+SSE流式输出+LangChain4j集成。感谢观看！

## 录屏注意事项

| 要点 | 说明 |
|------|------|
| 提前造数据 | 确保数据库有测试数据，界面内容丰富 |
| 网络稳定 | AI调用需要网络，确保DashScope API可用 |
| 先测一遍 | 正式录前先完整跑一遍，控制时间在3-5分钟 |
| 放大字体 | 浏览器Ctrl++放大2-3次，方便评委看清 |
| 录屏工具 | 推荐OBS（免费）或Windows自带Xbox Game Bar（Win+G） |
| 背景干净 | 关闭无关窗口，只留系统界面 |
| 鼠标慢移 | 操作时鼠标移动放慢，让评委看清操作位置 |

## 启动服务命令

```bash
# 终端1：启动后端
cd e:\software\FIVA_Assistant
.\mvnw.cmd spring-boot:run

# 终端2：启动前端
cd e:\software\FIVA_Assistant\frontend
npm run dev
```

- 前端：http://localhost:5173
